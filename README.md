# 灯野工業（制作例）スクロール演出つき企業サイト

> **このサイトは制作例です。会社名・製品・人物はすべて架空です。**

「スクロールに合わせて場面が切り替わる世界観演出」と「すぐ使える製品検索」を、同じサイトの中で両立させたデモです。
メーカー・ブランドの公式サイトリニューアルで、ストーリー性と実用性の両方がほしい場合を想定しています。

## 何を示しているか

| ページ | 内容 |
|---|---|
| `index.html` | 4場面のスクロール演出（夜の工房 → 光が生まれる → 街に灯る → 製品へ）。案内役「ともる」が台詞を話しながら進む。後半に会社紹介と製品入口。 |
| `products.html` | 演出なしの製品検索。用途・設置環境・色温度・IP等級・価格帯の絞り込み、品番/キーワード検索、比較（3件まで）、お気に入り、最近見た製品。条件はURLに反映（共有可）。 |
| `product.html?id=…` | 製品詳細。仕様表、印刷用レイアウト、ダミー仕様書（`spec.html`。PDFではない）へのリンク。 |
| `contact.html` | 問い合わせフォーム。`?sku=` で品番を事前入力。クライアント側の検証のみ。送信は行わず、確認表示だけ。 |

## 演出と製品検索を分ける、という設計

演出は印象づくりに、検索は目的達成に効きますが、同じ画面に混ぜると互いを邪魔します。そこで次のように分けています。

- ヘッダーに **「製品をさがす」ボタンを常時表示**（1クリックで `products.html`）。
- ヘッダーの **「演出をスキップ」** で、演出を飛ばして製品入口（検索窓と用途カテゴリ）へ1クリックで移動。
- 製品検索ページ群は GSAP / Lenis を読み込まない、演出なしのページ。
- 演出が不要な人・苦手な人向けに「動きを減らす」を用意（後述）。

## スクロール場面の作り方

- `js/story.js`。GSAP の **ScrollTrigger で `#story` を `pin`** し、1本のタイムライン（4場面分）を **`scrub: true`** でスクロール量に同期。スクロール距離は「画面高さ × 4」。
- 各場面は3層のSVG（`layer-bg / mid / fore`）を別速度で横移動（視差）。場面の切り替えは絵のクロスフェード。
- ともるは `x`（歩く）と `y`（弾む）をスクロールで動かし、台詞の吹き出しは位置に応じて出入り。
- 場面ごとの演出: 月と星の動き／光の放射・プリズム／窓と街灯が順に点灯・空の時間変化／製品シルエットが浮かぶ。
- 進行表示（右側または下部）は現在の場面を `aria-current="step"` で示し、クリックでその場面へ移動。
- アニメ対象は **transform と opacity のみ**（SVGの変形含む）。
- 慣性スクロールは Lenis（`ScrollTrigger.update` と連動）。
- 遅延生成: 星・光の筋・街の窓（数百個の`rect`）は、その場面が近づくまで生成しない（最初は場面1・2だけ）。静止モードでは IntersectionObserver で近づいたときに生成。
- HTMLは演出なしでも成立する静止レイアウトが既定で、JSが有効なときだけ `.is-scrub` を付けてピン表示に切り替えます。

## 動きを減らす（reduced motion）

- OSの `prefers-reduced-motion: reduce`、またはヘッダーの **「動きを減らす」トグル**（`localStorage` の `tm-reduce-motion` に保存）で有効。
- 有効時はピン・スクラブ・Lenisを使わず、4場面が縦に並ぶ静止セクションになります。台詞は全文表示、すべて読めます。
- トグルはページ再読込なしで即時に切り替わります（OS設定で有効な場合はトグルが無効化され、常に静止）。

## 音の方針

- **既定OFF。自動再生しません。** ヘッダーの「音」ボタン（`aria-pressed`）を押したときだけ、Web Audio API で穏やかな環境音（サイン波＋ローパス＋ゆっくりした揺らぎ）を生成。音声ファイルは使っていません。
- 場面が変わると音の高さが変わり、小さなベル音が1回鳴ります。OFFで約1秒かけて消音。

## ローカルで動かす

ビルド不要。ES modules と `fetch` を使うため、`file://` ではなく静的サーバー経由で開いてください。

```
npx serve .
# または
py -3 -m http.server 4173
```

GitHub Pages など静的ホスティングにそのまま置けます（外部CDN・外部フォント・外部画像は使っていません）。

## 検証

`npm i` のあと `node scripts/verify.mjs`（playwright-core + インストール済みの Chrome、内蔵の静的サーバーを使用。別の場所の playwright-core を使う場合は環境変数 `PLAYWRIGHT_CORE` にパスを指定）。375 / 768 / 1280px で全ページを読み込み、コンソールエラー、横はみ出し、各場面のスクロール位置でのスクショ（`screenshots/`）、スキップ導線、フィルタ・URL復元・比較・お気に入り・最近見た製品、`?sku=` 事前入力とフォーム検証、reduced-motion、音の既定OFF、印刷CSSを確認します。結果は `screenshots/verify-report.json`。
実機の各種ブラウザ・実機スマホでの確認や、スクリーンリーダーでの読み上げ確認は行っていません。
