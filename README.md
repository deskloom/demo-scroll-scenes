# 灯野工業（制作例）スクロール演出つき企業サイト

> **このサイトは制作例です。会社名・製品・人物はすべて架空です。**

「スクロールに合わせて場面が切り替わる世界観演出」と「すぐ使える製品検索」を、同じサイトの中で両立させたデモです。
メーカー・ブランドの公式サイトリニューアルで、ストーリー性と実用性の両方がほしい場合を想定しています。

## 何を示しているか

| ページ | 内容 |
|---|---|
| `index.html` | 4場面のスクロール演出（夜の工房 → 光が生まれる → 街に灯る → 製品へ）。技術図面調の図版に、短いナレーションが1行ずつ添う。後半に会社紹介と製品入口。 |
| `products.html` | 演出なしの製品検索（左に条件・右に結果）。用途・設置環境・色温度・IP等級・価格帯の絞り込み、品番/キーワード検索、比較（3件まで）、お気に入り、最近見た製品。条件はURLに反映（共有可）。 |
| `product.html?id=…` | 製品詳細。主要仕様（W・lm・K・IP）、仕様表、配光イメージ（模式図）、印刷用レイアウト、ダミー仕様書（`spec.html`。PDFではない）へのリンク。 |
| `contact.html` | 問い合わせフォーム。`?sku=` で品番を事前入力。クライアント側の検証のみ。送信は行わず、確認表示だけ。 |

## デザインの方針

「光だけが色を持つ」。照明メーカーの商品は光なので、画面は墨と紙とヘアラインだけで組み、アンバーは発光面・光の円錐・主ボタン・現在地にだけ使います。

| 役割 | 色 |
|---|---|
| 墨（暗い面・本文） | `#111214` |
| 紙（明るい面） | `#F2EFE9` |
| 白（カード・入力欄） | `#FBFAF7` |
| 灯（光・唯一のアクセント。明るい面の文字は `#8A5A12`） | `#E9A23B` |
| 鋼（補助文字） | `#5E6168` |
| 線（ヘアライン） | `#D9D4CB` |

- 書体：見出しは明朝、本文はゴシック、数値と品番は等幅・欧文。すべてOS標準フォント（Webフォントは読み込みません）。
- 図版：写真の代わりに、演出は寸法線・断面図・立面図の「技術図面」、製品は明るいスタジオで点灯した姿をSVGで描画（`js/common.js` の `productArt`）。製品詳細には形状から描いた配光の模式図を添えています（測定値ではありません）。
- 大胆なのは1か所だけ：場面2で「ひとつの光源がレンズで整った光になる」瞬間。他は静かに。
- 場面ごとに「文が入る → 静止して読める区間 → 出る」を分け、演出中でも文が読めることを優先。

## 演出と製品検索を分ける、という設計

演出は印象づくりに、検索は目的達成に効きますが、同じ画面に混ぜると互いを邪魔します。そこで次のように分けています。

- ヘッダーに **「製品をさがす」ボタンを常時表示**（1クリックで `products.html`）。
- ヘッダーの **「演出をスキップ」** で、演出を飛ばして製品入口（検索窓と用途カテゴリ）へ1クリックで移動。
- 製品検索ページ群は GSAP / Lenis を読み込まない、演出なしのページ。
- 演出が不要な人・苦手な人向けに「動きを減らす」を用意（後述）。

## スクロール場面の作り方

- `js/story.js`。GSAP の **ScrollTrigger で `#story` を `pin`** し、1本のタイムライン（4場面分）を **`scrub: true`** でスクロール量に同期。スクロール距離は「画面高さ × 4」。
- 各場面は3層のSVG（`layer-bg / mid / fore`）を別速度で横移動（視差・控えめ）。場面の切り替えは絵の短いクロスフェード。広い画面では図版を右側に寄せ、左を文に譲ります。
- ナレーション（時刻つきの1行）は場面の前半・後半で1行ずつ入れ替わります。
- 場面ごとの演出: 工房の窓がひとつだけ灯る／LEDチップ点灯 → 光の円錐が伸びる・各部の注記が順に出る／窓と街路灯が順に点灯・空が夜へ／4種の器具が下りてきて床を照らす。
- 進行表示（右側または下部）は現在の場面を `aria-current="step"` で示し、クリックでその場面へ移動。
- アニメ対象は **transform と opacity のみ**（SVGの変形含む）。
- 慣性スクロールは Lenis（`ScrollTrigger.update` と連動）。
- 遅延生成: 星・街の窓（数百個の`rect`）は、その場面が近づくまで生成しない（最初は場面1・2だけ）。静止モードでは IntersectionObserver で近づいたときに生成。
- HTMLは演出なしでも成立する静止レイアウトが既定で、JSが有効なときだけ `.is-scrub` を付けてピン表示に切り替えます。

## 動きを減らす（reduced motion）

- OSの `prefers-reduced-motion: reduce`、またはヘッダーの **「動きを減らす」トグル**（`localStorage` の `tm-reduce-motion` に保存）で有効。
- 有効時はピン・スクラブ・Lenisを使わず、4場面が縦に並ぶ静止セクションになります。台詞は全文表示、すべて読めます。
- トグルはページ再読込なしで即時に切り替わります（OS設定で有効な場合はトグルが無効化され、常に静止）。

## 音の方針

- **既定OFF。自動再生しません。** ヘッダーの「音」ボタン（`aria-pressed`）を押したときだけ、Web Audio API で穏やかな環境音（サイン波＋ローパス＋ゆっくりした揺らぎ）を生成。音声ファイルは使っていません。
- 場面が変わると音の高さが変わり、小さなベル音が1回鳴ります。OFFで約1秒かけて消音。

## ローカルで動かす

ビルド不要。ES modules と `fetch` を使うため、`file://` ではなく静的サーバー経由で開いてください。

```
npx serve .
# または
py -3 -m http.server 4173
```

GitHub Pages など静的ホスティングにそのまま置けます（外部CDN・外部フォント・外部画像は使っていません。GSAP / Lenis は `vendor/` に同梱したバージョン固定のファイルを読み込みます）。

## 検証

`npm i` のあと `node scripts/verify.mjs`（playwright-core + インストール済みの Chrome、内蔵の静的サーバーを使用。別の場所の playwright-core を使う場合は環境変数 `PLAYWRIGHT_CORE`、Chrome 以外の Chromium を使う場合は `CHROME_PATH` に実行ファイルのパスを指定）。375 / 768 / 1280px で全ページを読み込み、コンソールエラー、横はみ出し、各場面のスクロール位置でのスクショ（`screenshots/`）、スキップ導線、フィルタ・URL復元・比較・お気に入り・最近見た製品、`?sku=` 事前入力とフォーム検証（エラー・確認表示を3幅で撮影）、reduced-motion、音の既定OFF、印刷CSSを確認します。結果は `screenshots/verify-report.json`。
実機の各種ブラウザ・実機スマホでの確認や、スクリーンリーダーでの読み上げ確認は行っていません。
